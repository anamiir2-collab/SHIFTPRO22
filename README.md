# SHIFTPRO 6.5.0 — Shift Management & Smart Wallet PWA

تطبيق لإدارة الورديات والحضور وساعات العمل والرواتب والإجازات والتقارير والمحافظ الشخصية، بواجهة عربية أولًا ودعم كامل للإنجليزية. يعمل كتطبيق ويب تقدمي (PWA) ويمكن استخدامه دون اتصال بعد تحميل الملفات الأساسية.

A shift-management, attendance, payroll, leave, reports, and personal-wallet PWA with Arabic-first RTL support and English LTR support. The app can work offline after its application files are cached.

## Current Mero assistant

Mero is a **local task assistant** with optional speech playback. Neural speech is generated by the separate Piper service on the user's own computer. It provides tappable task options and routes supported requests to existing SHIFTPRO functions through `js/assistant-router.js`.

- Task groups cover navigation, attendance and shifts, salary, wallet, leaves, reports, backup, settings, labor-law search, and help.
- Task buttons invoke existing application actions rather than simulating results.
- Check-in, check-out, financial changes, backup, and other consequential actions use confirmation where required by the router.
- Requests with missing required details ask the user to clarify.
- Unsupported or unavailable functions are identified clearly.
- Mero does not call an external AI service or send chat messages to an AI provider. Optional speech sends assistant reply text only to the loopback Piper service at `127.0.0.1:8765`; it does not request microphone access, record audio, or recognize speech.
- The Web Speech fallback may rely on the browser/operating-system implementation and cannot guarantee zero network use. For strict offline privacy, select **Piper local only** and confirm a local voice model is installed.
- The assistant uses a strict allowlist of known intents. It does not execute generated JavaScript or arbitrary commands.
- Voice preferences are stored in `localStorage` (`shiftpro_mero_tts_v2`; legacy v1 keys migrated). No conversation text or audio is stored in settings, logs, or the repository.

## Privacy and data handling

- SHIFTPRO's operational records are handled by the app's existing local storage and modules.
- Mero invokes supported local application functions and does not send chat content or work records to an external AI service.
- Voice playback is optional and disabled until the user enables it. Preferences are stored in localStorage.
- Backup files can contain personal, attendance, salary, and wallet data. Store exported backups securely.
- The privacy policy is available at [privacy-policy.html](./privacy-policy.html). Review it whenever app storage or integrations change.

The app may still load the site itself and optional font resources required by the current UI. See the privacy policy for details.

## Optional local voice for Mero

Mero can read its replies aloud with a genuinely local neural voice (Piper) running on the user's own computer. See [`local-tts/README.md`](./local-tts/README.md) for the full setup, platform support matrix, troubleshooting, and API reference.

- **Windows:** run `local-tts\start-tts.bat` (installs dependencies and offers the Arabic voice `ar_JO-kareem-medium` download on first run), keep the window open, then open Mero and press "تشغيل الصوت".
- **Linux/macOS:** `./local-tts/start-tts.sh`.
- Verify with `curl http://127.0.0.1:8765/health` (`ready: true`). Models install explicitly via `local-tts/download-models.py`; no model weights are committed to Git.
- Engine modes: **local with system fallback**, **Piper local only** (strict privacy, no silent fallback), or **system voice**. The browser fallback is labeled in the UI because Web Speech cannot be guaranteed offline.
- The hosted GitHub Pages site cannot start a local service on a visitor's device; there, only the labeled browser fallback may be available. Capacitor/Android native speech is not implemented in this branch.
- Voice controls remember preferences per language, stop instantly on demand, never speak user messages or replay historical replies, and never list uninstalled voices.

## Run locally

The frontend is a static site. From the repository root, run:

```bash
python3 -m http.server 8000
```

Then open [http://localhost:8000](http://localhost:8000). Service-worker features require HTTPS or localhost.

## Tests

Install the development dependencies and run the Jest suite:

```bash
npm install
npm test
```

Report only tests that were actually run. Browser-only flows, mobile layouts, and the deployed GitHub Pages version should also be checked in a real browser.

## Safety and maintenance notes

- Preserve the existing SHIFTPRO modules and local data formats when changing Mero.
- Keep Arabic right-to-left and English left-to-right behavior consistent.
- Do not add API keys, tokens, passwords, or sensitive user data to frontend files.
- Do not claim a task succeeded unless the underlying function reports a result that supports that claim.
- Keep the privacy policy synchronized with the actual implementation.
